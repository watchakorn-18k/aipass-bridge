# Stop Slop - Anti-AI Prose & Summarization Skill

Eliminate predictable AI tells, throat-clearing, and artificial fluff from summaries.

## Core Directives

1. **Cut Throat-Clearing Openers:**
   - NEVER start with: "สรุปข้อมูลจากเนื้อหาที่ให้มาครับ:", "Here is the summary:", "In summary:", "The truth is:", "Let me be clear".
   - Jump directly into the factual point on line 1.

2. **Cut Conversational Fluff & Sign-Offs:**
   - NEVER end with: "คุณต้องการให้ผมช่วยอะไรเพิ่มเติมไหมครับ?", "Let me know if you need further assistance", "Hope this helps!".
   - Finish the summary cleanly with no trailing pleasantries.

3. **Avoid Binary Contrasts & Telegraphed Drama:**
   - AVOID: "Not because X, but because Y", "X isn't the problem, Y is", "It feels like X, but actually Y".
   - State facts directly without rhetorical buildup.

4. **Active Voice & Concrete Specifics:**
   - Focus on concrete facts: exact names, numbers, salaries, deadlines, requirements, and tech stacks.
   - Use active voice and precise human subjects.

5. **Clean Markdown Structure:**
   - Use crisp headings (`##`, `###`), structured bullet points (`*`), and code blocks with language identifiers.
